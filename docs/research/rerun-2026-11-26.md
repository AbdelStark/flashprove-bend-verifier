# Full rerun on main, 2026-11-26

> Status: frozen

After the speed pass and the documentation cleanup, we reran every conformance target and every benchmark on one revision, so the numbers in the README all come from the same build. The revision is `05b2268`. Its Bend source digest is `0922c00decdebecae5c114f23df0c00be3b3a843bd39c360e2abd8db3c14991e`. Its verification code is the same as `b4a8c4b`, which the [speed pass](speed-pass.md) measured, except for one unused definition that has since been removed. [Raw logs and identities](data/rerun-m4/conformance.json)

Everything ran on one Apple M4 Max (12 performance and 4 efficiency cores) under macOS 26.6.2 with Apple Clang 21.0.0. Normal desktop services were running and nothing was pinned to a CPU. The conformance runs went first. The benchmarks followed one at a time, after the conformance runs had finished.

## How this compares with the speed pass

The same verification code, measured again in a different session, came out 3–6% faster on Bend's side:

| Fixture | Workers | Speed pass | Rerun |
| --- | ---: | ---: | ---: |
| full-size vs. Lean | 1 | 18.597 s | 17.636 s |
| full-size vs. Lean | 16 | 10.240 s | 9.898 s |
| full-size vs. C++ | 1 | 18.570 s | 18.025 s |
| accepted-proof vs. C++ | 1 | 1.925 s | 1.866 s |

Lean (57.9–59.3 s against 60.1 s) and C++ (8.06 s against 8.19 s) moved by similar amounts in the same direction, so this looks like a difference in machine state rather than in the code. Ratios within one paired run are the reliable figures. The 1-worker Bend/Lean ratio moved from 3.23× to 3.28×. The parallel ratio moved from 5.87× to 5.89×.

## Reproduce

```sh
make bootstrap upstream standalone oracle lean-baseline
make standalone-full standalone-extended stages-full worker-parity
make fuzz FUZZ_ARGS="-n 128 --seed results-2026-11-26"
make benchmark-workers BENCH_ARGS="--worker-counts 1 2 4 8 12 16"
for n in 1 12 16; do make benchmark-onbytes BENCH_ARGS="--workers $n"; done
make benchmark-standalone
```

The kernel check needs `lean` v4.34.0 on `PATH`. The official release archive for your platform is enough. Then run `.toolchain/bend/bin/bend src/standalone.bend --verdict`.
